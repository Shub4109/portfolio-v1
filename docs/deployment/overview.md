## Deployment Target

**Candidate:** Vercel (primary consideration)

**Rationale (pending ADR):**
- Zero-config deployment for Next.js
- Edge network CDN
- Preview deployments per PR
- Built-in analytics option
- Environment variable management

**Alternatives considered:** Netlify, Cloudflare Pages, Railway

---

## Release Process

```
feature/* ──► develop ──► main ──► production
                │
                └── Preview deployment per PR
```

1. Merge PR into `develop`
2. Verify preview deployment passes all checks
3. Create a release PR: `develop` → `main`
4. Update `CHANGELOG.md` and bump version in `package.json`
5. Merge to `main` — triggers production deployment
6. Tag the release: `git tag v1.x.x`
7. Publish GitHub Release with notes
