---

## Design Principles

1. **Credibility first** — every visual decision should reinforce professional authority
2. **Content is primary** — design frames content; it never competes with it
3. **Accessible by default** — WCAG 2.1 AA compliance is a design constraint, not an afterthought
4. **Performance-aware** — decorative elements are earned; every asset has a performance cost
5. **Consistent, not rigid** — a design system governs spacing, color, and type; it does not prevent creativity
